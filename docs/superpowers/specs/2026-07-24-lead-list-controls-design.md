# Управление списком заявок

## Цель

Сделать список заявок быстрее для ежедневной обработки без изменения модели данных или добавления зависимостей.

## Изменения

1. Поиск учитывает номер телефона наряду с именем, компанией и email.
2. Над списком отображается число найденных заявок.
3. Переключатель выводит требующие внимания заявки первыми.
4. Фильтр оставляет только заявки без назначенного ответственного.

## Поведение

Все фильтры работают совместно. Сброс фильтров возвращает исходный порядок списка и выключает дополнительные переключатели. Для каждого изменения добавляется проверка пользовательского сценария.
